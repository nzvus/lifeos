# Ledger — every decision and intention, with its source

Why: the developer, 30 Oct: «molte scelte che avevamo fatto in passato o avevamo pensato
per il futuro mi sembra che ogni volta te le dimentichi». This file is read **first** by
every session, before any design or code. One line per decision or intention, the source
in brackets. Status: **D** decided and in force · **v2** built in v2 · **v1** only in v1 ·
**F** wanted for the future · **S** superseded (by what) · **?** open.
When a line changes, edit it here in the same PR. Built by reading all the docs in order
(progress at the bottom).

**IDs are stable**: a line keeps its ID for ever (a superseded line stays, marked S, with what
replaced it); new lines take the next number of their section. Boards, dossiers, plans and PRs
cite the IDs they follow («Ledger: UI-12, FOOD-03»). `scripts/check.py` checks that every ADR and
dossier is cited here, that every line has an ID, a status and a source, and that IDs are unique.
